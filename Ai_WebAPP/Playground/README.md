# 데이터베이스 실습 사이트 — 로컬(내 컴퓨터) 실행용

SQL Playground · SQL Tutorial · ERD Playground 세 가지 실습 도구가 들어 있는
**완전히 독립적인 실습 사이트**입니다. 설치도, 서버도, 인터넷도 필요 없습니다.
USB에 담아 교실 컴퓨터에 복사해서 바로 쓸 수 있습니다.

---

## 1. 실행 방법

**`index.html` 을 더블클릭하세요.** 그게 전부입니다.

브라우저(Chrome, Edge, Whale, Safari, Firefox 최신 버전)가 열리면서
실습 첫 화면이 나타납니다. 첫 화면에서 각 도구로 들어갈 수 있습니다.

> 참고: 이 로컬판에서는 데이터베이스가 메모리에서 실행되므로
> **페이지를 새로고침하면 DB가 처음 상태로 돌아갑니다** (처음 상태 =
> seed 데이터 / 빈 DB). 작성 중인 쿼리 탭은 브라우저에 저장되어 유지됩니다.
> 만든 데이터를 남기려면 **내보내기 ▾**로 DB(.sqlite/.sql)나 쿼리 탭(.sql)을
> 파일로 저장하고, 다음 수업에 **가져오기 ▾**로 다시 불러오세요.
> 과제 제출도 이 파일로 하면 됩니다.

## 2. 딱 하나만 수정하면 됩니다: `site-config.js`

`site-config.js` 파일을 메모장(또는 아무 텍스트 편집기)으로 열어
**과목명, 선생님 성함, 학교 이름, 학기, 색상**을 수정하고 저장한 뒤,
브라우저에서 새로고침하세요. 첫 화면과 세 실습 도구 전체에 반영됩니다.

```js
courseTitle: "데이터베이스 실습",   ← 과목/사이트 이름
teacherName: "홍길동",              ← 선생님 성함
schoolName:  "한국중학교",          ← 학교 이름
semester:    "2026학년도 1학기",    ← 학기
colors: {
  base:  "#002D56",                 ← 기본 색 (제목·버튼·배경)
  point: "#8D7150",                 ← 강조 색
},
```

따옴표(`"`)와 쉼표(`,`)만 지우지 않으면 됩니다.
색상 코드는 구글에서 "color picker"를 검색해 `#RRGGBB` 값을 복사하세요.

## 3. 폴더 구성

```
├── index.html         ← ★ 더블클릭으로 실행 (첫 화면)
├── site-config.js     ← ★ 선생님이 수정하는 유일한 파일
├── config-apply.js    ← 설정 반영 스크립트 (수정 금지)
├── shared.css / .js   ← 공통 디자인·동작
├── playground/        ← SQL Playground (자유 실습 / 빈 DB 모드)
├── sql-tutorial/      ← SQL Tutorial (단계별 학습)
├── erd-playground/    ← ERD Playground (ER 다이어그램 설계)
└── sample-csv/        ← CSV 업로드 연습용 예시 파일 3개 + 추천 쿼리 안내
```

**CSV 업로드 실습**: `sample-csv/` 폴더에 연습용 파일 3개(조인·집계·NULL 연습)와
파일별 추천 쿼리 안내문이 있습니다. SQL Playground의 `CSV 업로드` 버튼으로
올려서 사용하세요.

폴더와 파일의 위치·이름을 바꾸면 도구끼리 서로를 찾지 못해 동작하지 않습니다.

## 4. 자주 묻는 질문

- **인터넷이 필요한가요?** — 필요 없습니다. SQL 엔진(SQLite), 편집기, 차트,
  ERD 다이어그램 라이브러리까지 전부 폴더 안에 들어 있습니다.
- **학생 컴퓨터마다 설치해야 하나요?** — 설치할 것이 없습니다. 이 폴더를
  복사해 두고 `index.html`만 열면 됩니다.
- **학생이 쓴 쿼리·데이터는 어디로 가나요?** — 각자 컴퓨터의 브라우저
  안에서만 처리됩니다. 외부로 전송되지 않으며, 새로고침하면 DB는 초기화되고
  쿼리 탭은 유지됩니다.
- **여러 학생이 동시에 쓸 수 있나요?** — 각자 컴퓨터에서 각자 실행하는
  방식입니다. 전체가 링크로 접속하는 웹사이트가 필요하면 **GitHub Pages
  배포용 폴더**(`teacher-site-github`)를 사용하세요. 그쪽은 저장(OPFS)도
  지원해서 새로고침해도 DB가 유지됩니다.
- **파일을 열었는데 화면이 하얗거나 도구가 안 떠요** — 아주 오래된
  브라우저(Internet Explorer 등)에서는 동작하지 않습니다. Chrome/Edge/Whale
  최신 버전으로 열어 보세요.
- **"공유" 버튼은 뭔가요?** — 현재 쿼리 탭들을 담은 링크를 복사합니다. 로컬판
  링크는 `file://` 로 시작하는 **내 컴퓨터 경로**라서, 같은 컴퓨터·같은 폴더
  위치에서만 열립니다. 다른 사람에게 쿼리를 보내려면 링크 대신 쿼리 텍스트를
  복사해 주거나, GitHub Pages판(주소가 https)을 사용하세요.
