실기 시험 개요

제1과목 모델링과 제2과목 프린팅의 시험 흐름과 주의사항을 확인하세요.

1제1과목: 3D 모델링

  • 제한시간: 1시간
  • 평가내용: 부품 1, 2 모델링 및 어셈블리(조립)
  • 필수사항: 비번호 각인, 조립부 공차(±1mm 이하) 적용
  • 제출파일: 3D CAD 원본, STEP, STL, G-code 등(감독관 지시 참조)

2제2과목: 3D 프린팅

  • 제한시간: 2시간
  • 평가내용: 프린터 세팅, 출력, 서포트 제거, 후가공
  • 핵심주의: 슬라이싱 출력 예상 시간 80분 이내 세팅
  • 실격주의: 후가공(서포트 제거) 중 부품 파손 시 즉시 실격

합격 루틴 6단계

빠르게 만드는 것보다 검증 가능한 순서로 작업하는 것이 중요합니다.

STEP 01

도면 분석

기준면, 중심축, 대칭, 반복 형상과 핵심 치수를 먼저 표시합니다.

STEP 02

스케치 구속

완전구속을 목표로 치수와 기하 구속을 적용합니다.

STEP 03

피처 모델링

돌출·회전·컷·필렛·패턴 순서를 단순하게 유지합니다.

STEP 04

어셈블리

기준 부품을 고정하고 조립 구속과 간섭을 확인합니다.

STEP 05

파일 제출

요구 파일명과 형식, 저장 위치를 두 번 확인합니다.

STEP 06

출력 준비

방향·서포트·레이어·접착 설정을 검토해 G-code를 생성합니다.

중요: 이 웹앱은 반복 훈련용입니다. 시험 직전에는 반드시 Q-Net의 최신 공개문제, 수험자 유의사항, 지참준비물, 시험장별 사용 프로그램을 다시 확인하세요.

시험전략

공식 시험시간 3시간을 기준으로 한 학습용 시간 배분 예시입니다.

0~10분

도면 해석

부품 수, 대칭 여부, 축 기준, 조립 관계, 누락하기 쉬운 구멍·홈·필렛을 표시합니다.

10~75분

부품 모델링

복잡한 부품부터 시작하되, 중간 저장과 치수 검증을 반복합니다.

75~105분

어셈블리·간섭 확인

기준 부품 고정 → 조립 구속 → 자유도·간섭·방향 확인 순서로 점검합니다.

105~125분

파일 변환·제출 점검

원본, STP, STL 등 요구 형식을 저장하고 실제로 다시 열리는지 확인합니다.

125~165분

슬라이싱·출력 준비

출력 방향, 서포트, 베드 접착, 온도, 속도, 예상 시간을 검토합니다.

165~180분

최종 검수

파일명, 제출 위치, 치수, 누락 피처, 조립 방향, 장비 안전 상태를 확인합니다.

모델링 단축 전략

CAD 프로그램과 관계없이 적용할 수 있는 공통 원칙입니다.

형상을 기능 단위로 분해

①기본 몸체: 가장 큰 부피를 먼저 생성
②제거 형상: 관통구멍, 홈, 포켓을 묶어서 처리
③반복 형상: 원형·직선 패턴으로 복제
④마감 형상: 필렛·모따기는 마지막에 적용

오류 복구가 쉬운 작업 순서

①스케치 이름과 피처 이름을 구분
②큰 단계가 끝날 때마다 다른 이름으로 저장
③외부참조와 불필요한 링크 최소화
④내보낸 파일을 새 문서에서 재확인

01프로그램 시작·접속

  1. Box·Cylinder 등 기본 형상을 작업 평면에 배치합니다.

  3. 제거할 형상은 Hole로 바꾼 뒤 대상과 함께 Group합니다.
  4. 복제·대칭·반복 기능으로 동일 형상을 빠르게 만듭니다.
  5. Perspective보다 Orthographic 보기에서 치수와 정렬을 재확인합니다.

학습 가이드

설치부터 시험용 파일 생성까지 순서대로 확인하세요.

01설치 방법

  1. 학교 또는 개인에게 배정된 SOLIDWORKS 라이선스·시리얼 번호를 확인합니다.
  2. 공식 다운로드 페이지에서 사용 가능한 버전을 선택합니다.
  3. SOLIDWORKS Installation Manager를 실행하고 개별 설치를 선택합니다.
  4. 제품 선택과 설치 위치를 확인한 뒤 설치를 완료합니다.
  5. 첫 실행 후 단위계를 MMGS(mm, g, s)로 설정합니다.

02모델링·어셈블리 방법

  1. 새 파트에서 기준 평면을 선택하고 스케치를 완전구속합니다.
  2. 돌출 보스/베이스, 돌출 컷, 회전, 구멍 가공 마법사 순으로 기본 피처를 작성합니다.
  3. 필렛·모따기와 패턴은 형상 검증 후 적용합니다.
  4. 각 부품을 별도 저장하고 새 어셈블리에서 첫 부품을 고정합니다.
  5. 동심·일치·거리 메이트를 적용한 뒤 이동과 간섭 검사를 수행합니다.

04STL 파일 출력 방법

  1. 부품 또는 어셈블리를 엽니다.
  2. 파일 → 다른 이름으로 저장에서 STL을 선택하거나 파일 → Print3D를 사용합니다.
  3. 옵션에서 단위 mm, 해상도와 어셈블리 저장 방식을 확인합니다.
  4. 저장한 STL을 슬라이서에서 다시 열어 스케일·방향·메시 상태를 검사합니다.
주의사항: 버전과 라이선스에 따라 메뉴 이름이 다를 수 있습니다. 어셈블리를 하나의 STL로 저장할지 부품별로 저장할지 문제지 지시를 우선하고, STL 내보내기 옵션의 단위를 반드시 mm로 확인하세요.

학습 가이드

설치부터 시험용 파일 생성까지 순서대로 확인하세요.

01설치 방법

  1. Autodesk 계정에 로그인하고 교육용 권한 또는 체험·구독 권한을 확인합니다.
  2. 공식 페이지 또는 Autodesk Account에서 버전·언어·운영체제를 선택합니다.
  3. 설치 프로그램을 실행해 기본 구성요소를 설치합니다.
  4. 첫 실행 시 프로젝트 파일 위치와 기본 템플릿을 확인합니다.
  5. 문서 설정에서 길이 단위를 mm로 맞춥니다.

02모델링·조립 방법

  1. 새 Part에서 2D Sketch를 만들고 중심선·대칭·치수 구속을 적용합니다.
  2. Extrude, Revolve, Hole, Sweep, Pattern으로 피처를 작성합니다.
  3. Fillet·Chamfer는 마지막 단계에 배치해 수정성을 높입니다.
  4. 부품을 IPT로 각각 저장하고 새 Assembly에 Place합니다.
  5. 첫 부품을 Ground한 뒤 Constrain 또는 Joint로 위치를 결정하고 간섭을 분석합니다.

04STL 파일 출력 방법

  1. 파일 → 다른 이름으로 저장 → 사본 저장 또는 내보내기 → CAD 형식을 선택합니다.
  2. 파일 형식에서 STL을 선택합니다.
  3. Options에서 단위를 mm로 맞추고 필요한 경우 Resolution을 High로 설정합니다.
  4. STL을 슬라이서에 불러와 전체 크기와 곡면 분할 상태를 확인합니다.
주의사항: STL 자체에는 단위 정보가 명확하지 않을 수 있으므로 내보내기 옵션과 슬라이서의 단위를 모두 mm로 맞추세요. 조립품을 내보낼 때 부품이 서로 겹치거나 분리되지 않았는지도 확인해야 합니다.

학습 가이드

설치부터 시험용 파일 생성까지 순서대로 확인하세요.

01설치 방법

  1. Autodesk 계정으로 로그인하고 개인용·교육용·체험판 등 적합한 이용 자격을 선택합니다.
  2. 공식 페이지에서 설치 파일을 내려받아 실행합니다.
  3. 설치 후 로그인하고 새 프로젝트와 디자인을 생성합니다.
  4. Document Settings에서 Units를 mm로 변경합니다.
  5. 오프라인 시험 환경을 대비해 필요한 파일을 로컬로 내보내는 연습을 합니다.

공차(A, B)를 너무 좁게 주어 출력 후 부품 1과 부품 2가 붙어버려 움직이지 않으면 실격입니다.

비번호 각인 누락

도면에 지시된 위치에 자신의 비번호(수험번호)를 각인하지 않거나 잘못된 번호를 각인하면 오작으로 처리됩니다.

미완성 및 제출 누락

지정된 시간 내에 요구하는 모든 파일(보통 모델링 4개, 슬라이싱 1개 등 총 8개 포맷)을 저장하여 제출하지 못하면 실격입니다.

💡 예기치 못한 상황 대처

  • 정전 또는 기계 고장: 당황하지 말고 감독위원에게 즉시 보고하세요. "작업정지시간 + 5분"의 추가 시간이 부여됩니다.
  • 안전장구 미착용: 방진마스크 및 보호장갑 미착용 시 채점상 불이익(감점)이 있으니 반드시 착용하세요.
  • 베드 안착 실패: 출력 시작 후 1~2 레이어가 베드에 잘 붙는지(안착) 3~5분간 꼭 지켜보세요. 실패 시 즉시 중지하고 다시 출력해야 합니다.

과제명: 3D모델링작업

3D모델링 → 어셈블리 → 슬라이싱 순서로 수행하는 과제입니다.

3D모델링→어셈블리→슬라이싱
1. 요구사항

가. 3D모델링

  1. 주어진 도면의 부품 ①, ②를 1:1 척도로 모델링합니다.
  2. 상호 움직임이 발생하는 부위의 치수 A, B는 수험자가 결정하되 기준치수와의 차이를 ±1 mm 이하로 설정합니다.
  3. 도면에 지정된 위치에 부여받은 비번호를 음각으로 각인합니다. 글자체·크기·깊이는 도면과 유사하게 작업하며, 비번호 2번은 ‘2’ 또는 ‘02’처럼 각인할 수 있습니다.

나. 어셈블리

  1. 각 부품을 1:1 척도와 도면의 조립 상태로 어셈블리하고, 지정 위치에 비번호가 각인되어 있는지 확인합니다.
  2. 하나의 조립된 형태로 다음 파일을 저장합니다.
    • 사용 소프트웨어의 기본 확장자
    • STP(STEP) 확장자 - 버전이 여러 개면 상위 버전
    • 슬라이싱 작업용 STL 확장자
    • 움직이는 부분은 출력 가능성을 고려해 동작 범위 안에서 위치를 조정할 수 있음
    • 파일명은 부여받은 비번호로 저장

다. 슬라이싱

  1. 어셈블리 형상을 1:1 척도와 조립된 상태로 출력할 수 있도록 슬라이싱합니다.
  2. 수험자가 직접 출력할 3D프린터 기종을 확인하고 설정값을 결정하며, 예상 출력시간이 1시간 20분 이내가 되도록 합니다.
  3. 시험장 프린터에서 출력 가능한 확장자로 저장하고 파일명은 비번호로 지정합니다.

최종 제출파일

  • 출력 예상시간을 시험감독위원에게 확인받고 USB 또는 SD-card에 최종 파일을 저장해 제출합니다.
  • 모델링 채점은 STP 파일을 기준으로 하며, 감독위원이 다른 작업 파일을 추가로 요구할 수 있습니다.
2. 수험자 유의사항
  1. 시험 시작 전 장비 이상 유무를 확인합니다.
  2. 감독위원이 지정한 위치에 비번호 폴더를 만든 뒤 작업내용을 저장하고, 제출·시험 종료 후 저장내용을 삭제합니다.
  3. 인터넷 등 네트워크가 차단된 환경에서 작업합니다.
  4. 정전·기계고장에 대비해 수시 저장하며, 문제 발생 시 ‘작업정지시간 + 5분’의 추가시간이 부여됩니다.
  5. 시험 중에는 시험감독위원의 지시에 따라야 합니다.

실격 및 채점 제외

  1. 수험 도중 기권 의사를 표현한 경우
  2. 실기시험 과정 중 하나라도 불참한 경우
  3. 장비 조작·재료 취급 미숙으로 위해 우려가 있다고 감독위원 전원이 판단한 경우
  4. 봉인을 훼손하거나 저장매체를 주고받은 경우
  5. 휴대폰을 소지·사용하거나 인터넷·네트워크를 이용한 경우
  6. 3D모델링작업 또는 3D프린팅작업 중 하나라도 0점인 경우
  7. 감독위원의 정당한 지시에 불응한 경우
  8. 시험시간 안에 작품을 제출하지 못한 경우
  9. 최종 제출파일(어셈블리·슬라이싱) 중 하나라도 제출하지 않은 경우
  10. 슬라이서 예상 출력시간이 1시간 20분을 초과한 경우
  11. STP 어셈블리에 비번호가 없거나 다른 번호를 각인한 경우
  12. STP 어셈블리의 지정 위치에 음각 비번호를 각인하지 않은 경우
  13. 채점용 어셈블리를 1:1 척도로 제출하지 않은 경우
  14. 채점용 어셈블리를 조립된 상태로 제출하지 않은 경우
  15. 모델링 길이 치수가 한 곳이라도 ±2 mm를 초과한 경우

과제명: 3D프린팅작업

3D프린터 세팅 → 3D프린팅 → 후처리를 작업시간 구분 없이 수행합니다.

3D프린터 세팅→3D프린팅→후처리
1. 요구사항

가. 3D프린터 세팅

  1. 노즐·베드 등의 이물질을 제거해 출력 방해요소가 없도록 합니다.
  2. PLA 필라멘트 장착 여부와 소재 이상 유무를 점검해 정상 작동 상태로 만듭니다.
  3. 베드 레벨링 기능 등을 활용해 베드 위치를 설정합니다.
  4. 별도의 샘플 프로그램을 작성해 출력 테스트를 할 수 없습니다.

나. 3D프린팅

  1. 출력용 파일을 수험자가 3D프린터에 직접 입력합니다. 무선 네트워크를 이용한 데이터 전송은 사용할 수 없습니다.
  2. 3D프린터의 장비 설정값은 수험자가 결정합니다.
  3. 설정을 완료한 뒤 모델링 형상을 도면과 같은 1:1 척도와 조립된 상태로 출력합니다.

다. 후처리

  1. 출력 후 서포트와 거스러미를 제거해 제출합니다.
  2. 노즐·베드 등 사용한 프린터를 시험 전 상태와 같이 정리하고 감독위원에게 확인받습니다.
2. 수험자 유의사항
  1. 시험 시작 전 장비 이상 유무를 확인합니다.
  2. 출력용 파일은 1회 이상 출력할 수 있으나 시험시간 안에 작품을 제출해야 합니다.
  3. 정전·기계고장에 대비해 수시로 체크합니다. 문제 발생 시 ‘작업정지시간 + 5분’이 부여되며, 중간 재시작이 불가능하다고 판단되면 처음부터 다시 출력합니다.
  4. 장비 손상 우려가 있는 공구·재료는 사용 전 관리위원에게 확인받습니다.
  5. 시험 중 감독위원의 지시에 따라야 합니다.
  6. 날이 있는 공구와 고온 노즐의 위험을 막기 위해 보호장갑을 착용합니다. 미착용 시 채점상 불이익이 있을 수 있습니다.
  7. 출력 중 유해가스 차단을 위해 방진마스크를 착용합니다. 미착용 시 채점상 불이익이 있을 수 있습니다.
  8. 창문 개방·환풍기 가동 등으로 충분한 환기 상태를 유지합니다.

실격 및 채점 제외
